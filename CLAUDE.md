# Instructions for Claude

## PR activity monitoring

Do **not** proactively subscribe to PR activity (`subscribe_pr_activity`) after opening or merging a pull request, and do not ask the user whether to watch/monitor/babysit a PR. Watching PRs consumes the user's usage limit, so it must stay strictly opt-in: only subscribe when the user explicitly asks you to watch, monitor, or babysit a specific PR. This holds until the user says otherwise.
